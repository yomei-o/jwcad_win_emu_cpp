Jw_cad on jwemu — Windows 版の exe をそのままブラウザで

読み込んでいます…
ファイル — Jw_cad から見える C:\jww の中身。ここへドラッグ＆ドロップしても入れられます。 ● は入れたもの・Jw_cad が保存したもの（このブラウザに残ります）
C:\jww

これは何か

Windows 版 Jw_cad 10.03.6 の実行ファイル（Jw_win.exe）を、改造せずに x86 エミュレータの中で動かしています。Windows の API（user32・gdi32 など）はエミュレータの側で 作り直したもので、コモンコントロールは Wine の comctl32.dll です。 ファイルはブラウザの中だけに置かれ、どこにも送信されません。

操作

左クリック / 右クリックJw_cad の (L) / (R)。右ボタンが無いときは Ctrl＋クリック
ホイール拡大縮小（Jw_cad の設定どおり）
キーボード画面をクリックしてから。日本語入力もそのまま使えます

ファイルの扱い

「ファイルを入れる」で手元の .jww・.jws・.dxf・テンプレートなどを C:\jww に置けます。Jw_cad の「開く」で選べます。Jw_cad で保存した図面は数秒で一覧に 現れ、DL で手元に取り出せます。入れたファイルと保存した図面はブラウザの IndexedDB に 保存されるので、リロードしても消えません。

権利

Jw_cad の著作権は清水治郎・田中善文両氏にあります（使用条件は C:\jww\Jw_win.txt）。 comctl32.dll は Wine（LGPL）、フォントは IPAex（IPA フォントライセンス）ほか。詳しくは リポジトリの README をご覧ください。
